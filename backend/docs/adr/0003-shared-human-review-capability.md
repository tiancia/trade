# ADR-0003：共享人工审核能力与业务状态分离

状态：已采纳。

微博要求第三方人工审核，Telegram 接入暂留 TODO，后续其他业务域也要复用。
新增四层共享 `telegram` 模块，与 `ai` 一样禁止反向依赖业务域。domain 定义通用
ReviewRequest/ReviewDecision，application port 定义投递，infrastructure 提供不可用占位。
供应商接入及入站适配器以后实现，目前不创建空 HTTP 层或引入新依赖。

微博拥有正文、版本、有效期、审核状态和发布资格。消息送达不会批准帖子；认证后的回调
经组合/编排边界调用业务用例。模块、业务引用和正文版本组成投递身份。
Telegram 未接入或故障时停在待审核，不通过假批准绕过限制。
